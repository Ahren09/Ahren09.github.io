## Overview

SourceLearn studies how an LLM agent can progressively learn from a persistent authoritative source. It maintains a source model that represents how knowledge is structured, interpreted, and applied. Self-directed learning revisits incompletely understood material, while task-guided learning identifies recurring representational needs. Both mechanisms reconstruct persistent updates from the original source.
