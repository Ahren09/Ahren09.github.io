## Overview

TimeRSI develops task-specific forecasting pipelines around frozen time-series foundation models. A coding agent translates task descriptions into executable changes, evaluates revisions on historical forecasting windows, and uses forecast errors to guide further improvements. At deployment, an adaptive selector chooses among the resulting pipelines using feedback from completed forecasts under similar conditions.
